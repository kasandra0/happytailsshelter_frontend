## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone <your-repo-url>
cd happytailsshelter_frontend
```
### 2️⃣ Navigate to the app folder
```bash
cd app
```
### 3️⃣ Install dependencies
```bash
npm install
```
### 4️⃣ Run the development server
```bash
npm run dev
```
Navigate to Local:   http://localhost:5173/
